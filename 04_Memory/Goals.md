# Goals

## Project Memory

## Confirmed Goals
- Build Ameer as a free executive core that performs real work end-to-end.
- Preserve Ameer's identity, personality, memory, context and behavior independently from replaceable model providers.
- Give Ameer direct operational authority across existing sites, programs, repositories, files, workers, skills, connectors, credentials, VPS/local/VS Code and connected project services.
- Keep Founder approval limited to the sovereign gates defined in `06_Code/kernel/ameer_authority.py`.
- Support Arabic dialogue as a first-class context-aware interaction mode.
- Enable Ameer to create/remove/reassign workers and evolve skills according to task needs.
- Keep ChatGPT, Manus and other assistants optional resources rather than authorities or required operators.
- Require truthful execution evidence: Ameer does not claim a real action unless it actually occurred.

## Confirmed Roadmap Priorities
- Real execution across local and web environments.
- School workspace: classroom management, student distribution, records, worksheets, reports and print-ready outputs.
- Autonomous administration of existing technical assets and infrastructure.
- Provider/model switching without identity drift.
- Narrow sovereign approval gate with delegated trading exception.
