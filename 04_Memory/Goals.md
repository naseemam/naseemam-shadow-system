# Goals

## Project Memory

## Confirmed Goals
- Build Ameer as a trusted growth partner that follows founder approval.
- Preserve memory and knowledge with control and audit.
- Keep identity, memory, and rules separate from replaceable model providers.
- Support Arabic dialogue as a first-class interaction mode.
- Enable coordinated specialized agents under one executive authority.
- Protect privacy, including founder-owned website privacy and tracking protection requirements.

## Confirmed Roadmap Priorities
- Phase 0: security, authentication, real LLM activation, and local data encryption.
- Phase 1: permanent memory, approval flow, decision logging, audit logging, and memory search.
- Phase 2: core tools such as file reading, GitHub integration, and permission-gated tool use.
