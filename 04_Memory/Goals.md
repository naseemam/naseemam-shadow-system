# Project Memory — Goals

## Confirmed Project Goals
- Build Ameer as a trusted growth partner that follows founder approval.
- Preserve memory and knowledge with control and audit.
- Keep Ameer identity, memory, and rules separate from replaceable model providers.
- Support Arabic dialogue as a first-class interaction mode.
- Enable coordinated specialized agents under one executive authority.
- Protect privacy, including founder-owned website privacy and tracking protection requirements.

## Confirmed Roadmap Priorities
- Phase 0 focuses on securing the system, authentication, real LLM activation, and local data encryption.
- Phase 1 focuses on memory, approval flow, decision logging, audit logging, and internal memory search.
- Phase 2 focuses on core tools such as file reading, GitHub integration, and permission-gated tool use.
