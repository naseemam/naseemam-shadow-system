محادثة الأعمال

للتصميم والبرمجة وبناء المواقع واختبارها وإدارة المشاريع وتسليم الكود.

✓البناء والكتابة والاختبار والدفع والدمج تبدأ تلقائيًا.
!بطاقة القرار تظهر فقط قبل إنشاء موقع أو برنامج أو نظام أو مستودع مستقل جديد.
تظهر بطاقة القرار فور إنشاء طلب حساس. لاستعادة الطلبات المحفوظة من جلسة سابقة، استخدم الزر أدناه.
محادثة الأعمال مع أميرتظهر الأدلة وروابط المعاينة والموافقات في نفس المحادثة.

متابعة العملاء

نسخة إشرافية للبيانات المتاحة في متجر حلم الندى؛ هذه الشاشة للمتابعة ولا ترسل رسائل للعملاء.

تعرض النسخة الإشرافية ملفات العملاء وسجل المتابعة المتاح فقط. المحادثات التفصيلية لا تُعرض هنا ما لم تُربط قناة المتجر بها صراحةً.

الحوكمة

ينفذ أمير المخرجات داخل مشروع المدرسة باستقلال؛ وتظهر الموافقة فقط إذا احتاج إنشاء موقع أو برنامج أو نظام أو مستودع مستقل جديد.

مشروع التداول

لوحة تنظيمية لإدارة موقع التداول ووحداته. هذه الواجهة لا تنفذ أوامر تداول ولا تقدم توصية استثمارية.

وحدة تداول منظمة
موقع التداول

مساحة لبناء موقع التداول وصفحاته وواجهاته وإدارتها ضمن مشروع مستقل.

التداول والأوامر المالية ليست مفعّلة من هذه الشاشة. عند بناء أي تكامل مستقبلي، يجب أن يبقى التنفيذ الخارجي خاضعًا للحوكمة والموافقة المعتمدة.

الإدارة الشاملة

حالة أمير والعمال والتنفيذات والموافقات والمشاريع في مكان واحد.

الموافقات والتنفيذ

لا يطلب أمير موافقة للقراءة أو الكتابة أو البناء أو الاختبار أو النشر أو البريد أو الحذف أو إدارة العمال داخل الأصول القائمة. بطاقة القرار تظهر فقط عند إنشاء أصل رقمي مستقل جديد.

العمال والنماذج

أمير يختار العامل والنموذج الملائم للمهمة ولا يرتبط بمزوّد واحد.

سلطة أمير التنفيذية

أمير وكيل تشغيلي دائم داخل نظام الظل: يخطط ويصمم ويبني ويشغّل وينشر ويوجه العمال دون انتظار.

هذه الصفحة تشرح الدستور التشغيلي: التنفيذ هو الأصل داخل الأصول القائمة، والموافقة استثناء محدود لإنشاء أصل رقمي مستقل جديد.

استقلالية تشغيلية كاملة

يملك أمير التخطيط والتصميم والبرمجة والاختبار والتشغيل والنشر والبريد وإدارة المتجر والمدرسة والسجلات والوثائق والصور والفيديوهات وتوزيع العمال داخل الأصول القائمة.
