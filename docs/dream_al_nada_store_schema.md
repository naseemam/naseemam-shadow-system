# مخطط البرنامج الإداري لمركز حلم الندى

## النطاق

يرتبط `Store Agent` بأوركيستريتور أمير كعامل مستقل، ويعمل داخل نطاق مركز حلم الندى فقط. قاعدة البيانات الحالية هي SQLite مستمرة تحت `AMEER_DATA_DIR/.ameer/business.sqlite3`، ولا تُحفظ فيها مفاتيح أو أسرار مزوّد النموذج.

## الجداول الأساسية

| الوحدة | الجدول | الغرض |
|---|---|---|
| هوية المركز | `center_profile` | اسم المركز والمنطقة الزمنية والعملة وإعدادات التشغيل |
| المخزون | `products` | المنتجات والرموز والأسعار والكميات وحد إعادة الطلب |
| حركة المخزون | `inventory_movements` | سجل كل زيادة أو نقص مع السبب والتاريخ |
| الموظفون | `employees` | بيانات الموظفين والدور والحالة ووسائل التواصل |
| العملاء | `customers` | بيانات العملاء والملاحظات |
| الحجوزات | `bookings` | موعد الحجز والعميل والموظف والحالة والملاحظات |
| الطلبات | `orders` | الطلبات والإجمالي والحالة والعميل |

## قواعد الوصول

يملك Store Agent قراءة وكتابة داخل نطاق بيانات المركز بعد مراجعة أمير. لا يملك صلاحية الوصول إلى نطاق عامل آخر، ولا يستطيع تعديل الحوكمة أو قتل عمليات العمال أو تنفيذ أثر خارجي. أي إرسال أو حذف أو تغيير حساس أو تكامل خارجي يتوقف عند موافقة أمير ثم الموافقة النهائية للمؤسس.

## واجهات القراءة الأولية

- `GET /center/profile`
- `GET /center/dashboard`
- `GET /center/inventory`
- `GET /center/employees`
- `GET /center/bookings`

تُستخدم واجهات الكتابة مستقبلًا عبر مسار التفويض المركزي، وليس عبر endpoint غير محكوم مباشر.

## مسار الطلب

```text
المستخدم → أمير/Orchestrator → Store Agent → business.sqlite3
                    ↓
          سجل التنفيذ المركزي
                    ↓
       موافقة المؤسس عند الأثر الحساس
```

## حالات الاختبار الأولية

تم اختبار تهيئة ملف المركز، إنشاء منتج، إنشاء موظف، إنشاء حجز، وتوجيه أمر «اعرض لوحة حلم الندى» إلى Store Agent بنجاح محليًا.
